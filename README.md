# lib.saxonica-saxon-he

Local source mirror and packaging workspace for Saxon-HE (Saxonica's open-source XSLT/XQuery
processor, MPL 2.0 license).

## Layout

- `incoming/` - imported upstream source snapshots (versioned folders).
- `jars/` - built or collected jar artifacts used by distro build/deploy steps.
- `project.inf` - project metadata consumed by distro tooling.
